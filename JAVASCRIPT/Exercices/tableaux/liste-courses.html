Mini-projet : la liste de courses (consigne du PDF du formateur). Écrivez un programme qui gère une liste de courses dans la console (F12). La liste est un tableau stocké dans une seule variable. Chaque fonctionnalité possède sa propre fonction, au nom explicite ; ne répétez pas les blocs de code et utilisez les méthodes Array. 1. ajouterProduit(nom) ajoute un produit à la fin de la liste. 2. supprimerProduit(nom) supprime ce produit. S'il est absent, affichez « Produit introuvable : … » sans modifier la liste. 3. viderListe() supprime tous les produits. 4. afficherListe() affiche le nombre de produits, puis un produit par ligne. Si elle est vide, affichez « La liste de courses est vide ». Tests : ajoutez quatre produits et affichez la liste ; demandez avec prompt le produit à supprimer, supprimez-le et affichez ; videz et affichez. Exemple : pain, lait, riz, tomates → 4 produits. Après suppression de lait : pain, riz, tomates → 3 produits. Après vidage : La liste de courses est vide. Bonus : suppression sans tenir compte des majuscules ; refuser les doublons et les noms vides ou composés uniquement d'espaces ; ajouter trierListe() pour un tri alphabétique.
