# Centre Horizon

## Présentation du projet

**Centre Horizon** est un site web destiné à présenter un centre de formation et ses formations, notamment la formation **Développeur web**. Il permet aux visiteurs de découvrir les formations proposées et d'accéder à un formulaire de pré-inscription.

## Objectifs

* Présenter le centre de formation.
* Afficher les informations sur les formations proposées.
* Permettre aux utilisateurs de remplir un formulaire de pré-inscription.
* Créer une interface claire, simple et adaptée aux différents écrans.

## Technologies utilisées

* **HTML5** : structure des pages web.
* **CSS3** : mise en forme et personnalisation du site.
* **Bootstrap 5** : création d'une interface responsive et mise en forme des formulaires.

## Fonctionnalités

### Page d'accueil

Présentation du centre de formation et accès aux différentes sections du site.

### Page Formation

Présentation des informations relatives à la formation Développeur web.

### Page Pré-inscription

Formulaire permettant de renseigner les informations personnelles, le projet de formation, la situation actuelle, les motivations et, si nécessaire, un CV.

## Installation et utilisation

1. Télécharger ou cloner le projet.
2. Placer les fichiers dans le même dossier en respectant l'organisation du projet.
3. Ouvrir le fichier `index.html` dans un navigateur web.
4. Utiliser le menu de navigation pour accéder aux différentes pages.

Une connexion Internet est nécessaire pour charger Bootstrap depuis le CDN si le projet utilise cette méthode.

## Responsive design

Le site utilise les classes de Bootstrap 5 afin d'adapter l'affichage aux ordinateurs, aux tablettes et aux téléphones.
