Développeur web

Créer des sites et des applications, du HTML au back-end, en six mois de formation intensive et concrète.

Durée : 6 mois Niveau : débutant Présentiel à Creil Titre professionnel de niveau 5

Programme

Les six modules de la formation
Module Contenu Durée
1. Bases du web HTML, CSS, responsive, accessibilité 4 semaines
2. JavaScript Variables, fonctions, DOM, événements 4 semaines
3. Front-end Composants React, appels d'API 4 semaines
4. Back-end Node.js, API REST, bases de données SQL 5 semaines
5. Qualité Tests, sécurité, déploiement 3 semaines
6. Projet final Projet en équipe, préparation du titre 4 semaines

Compétences visées

  • Intégrer des maquettes responsives et accessibles
  • Développer des interfaces dynamiques en JavaScript
  • Concevoir une base de données et une API
  • Tester, sécuriser et déployer une application
